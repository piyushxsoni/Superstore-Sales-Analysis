# Superstore Sales Analysis

## 📌 Project Overview

This project analyzes Superstore sales data to understand sales performance, profitability, customer segments, product performance, discounts, and regional trends.

The project combines **Python, SQL, Excel, and Power BI** to perform data analysis and create interactive business dashboards.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- SQL
- Microsoft Excel
- Power BI

## 📊 Key Analysis

The project covers the following areas:

- Sales and Profit Analysis
- Customer & Product Analysis
- Regional Performance
- Category and Sub-Category Analysis
- Discount Analysis
- Order Analysis
- Customer Segment Analysis
- Sales and Profit Trends
